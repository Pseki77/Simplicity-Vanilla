Simplicity Vanilla is the cleanest version of a deadshot client that can ever be
It offers users with a downloadable version of deadshot

Open the SimplicityVanilla (application) file present in this folder to run the Client 

Simplicity Vanilla has the following features :

    1. Press F2 for screenshotting while mid game (also copies the image to your clipboard). The image is  saved to the path .../pictures/deadshot.io/

    2. Press F3 for immediately hiding simplicity while playing and press it again to bring the window back.

    3. Press F4 for saving a memory snapshot of 15 seconds long (works as long as passive recording is enabled in Simplicity Vanilla). Video is saved to the path .../videos/deadshot.io/

    4. Press F5 for enabling/disabling passive recording (is enabled by default).

    5. Press F1 for GUI Menu to toggle options like snapshot length, FPS at which snapshot is recorded, Change the color of breathing neon light on watermark and to enable and disable performance settings.

    6. An uptime recorder at the top of menu bar which indicates the time it has been since you started playing.

Notes
 > you may disable passive recording by pressing 6 as it may affect your FPS and performance.

 > Resizing the window restarts the recording, so wait about 15 seconds before saving.
